Im folgenden geht es um wahrgenommene Gruppenzugehörigkeiten zu Freundeskreisen.

In the following we ask you about perceived group memberships to social circles.

Bitte ordnen Sie die folgenden Personen Ihren verschiedenen Freundeskreisen zu. Ein Freundeskreis besteht aus Personen, die auch miteinander befreundet sind.

Please categorize the following people by their friend-group. Each friendship group is made up of people how are also friends with each other.

Geben Sie Personen im selben Freundeskreis dieselbe Nummer (1, 2, 3, ...). Falls eine Person keinem gemeinsamen Kreis angehört, vergeben Sie eine eigene Nummer. Jede Person kann nur einem Freundeskreis angehören.

Please give the people in the same friend-group the same number (1, 2, 3, ...). If a person belongs to no common group, give them their own number. Each person can only belong to one group.
