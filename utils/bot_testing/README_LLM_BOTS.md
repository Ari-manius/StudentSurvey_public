# LLM-Powered Bot Testing for oTree

This directory contains tools for running oTree bot tests using Ollama LLM to generate realistic, human-like survey responses instead of random values.

## Features

- **Realistic Responses**: LLM generates contextually appropriate answers based on question text and options
- **Consistent Personas**: 5 different student personas maintain consistent characteristics across all questions
- **Question-Aware**: Passes full question text and options to the LLM for informed responses
- **Fallback Support**: Automatically falls back to random responses if Ollama is unavailable
- **Hybrid Mode**: Can be enabled/disabled via environment variable

## Setup

### 1. Install Ollama

```bash
# macOS (Homebrew)
brew install ollama

# Or download from https://ollama.ai/
```

### 2. Start Ollama Server

```bash
ollama serve
```

### 3. Pull a Model

```bash
# Recommended: Fast and efficient
ollama pull llama3.2

# Or use a larger model for better quality
ollama pull llama3.1
```

### 4. Install Python Package

```bash
pip install ollama
```

### 5. Verify Setup

```bash
python utils/bot_testing/run-otree-bot-test-llm.py --check
```

## Usage

### Option 1: Use the LLM Bot Script (Recommended)

This uses a separate script that automatically enables LLM mode:

```bash
# Run with default settings (3 participants, verbose output)
python utils/bot_testing/run-otree-bot-test-llm.py

# Specify number of participants
python utils/bot_testing/run-otree-bot-test-llm.py 5

# Use quiet mode (no detailed LLM logging)
python utils/bot_testing/run-otree-bot-test-llm.py 5 --quiet

# Use a different model
OLLAMA_MODEL=llama3.1 python utils/bot_testing/run-otree-bot-test-llm.py 10
```

**Verbose output shows:**
- Which persona each bot is using
- Each page being processed
- Each field being generated by the LLM with the response value
- Summary of LLM vs random responses per page

Example output:

### Option 2: Enable LLM Mode in Regular Script

You can use the regular script with LLM mode enabled:

```bash
# Enable LLM bots via environment variable
USE_LLM_BOTS=1 python utils/bot_testing/run-otree-bot-test.py

# With custom model
USE_LLM_BOTS=1 OLLAMA_MODEL=llama3.1 python utils/bot_testing/run-otree-bot-test.py
```

### Option 3: Regular Random Testing

The original random-based testing still works as before:

```bash
# Standard random bot testing (fast)
python utils/bot_testing/run-otree-bot-test.py
```

## Configuration

### Environment Variables

- `USE_LLM_BOTS`: Set to `1` to enable LLM responses (default: `0`)
- `OLLAMA_MODEL`: Ollama model to use (default: `llama3.2`)

### Bot Personas

The system includes 5 different personas that maintain consistent characteristics:

1. **Conservative Student** - Age 20, Business major, optimistic about economy
2. **Progressive Student** - Age 22, Social sciences, concerned about inequality
3. **Moderate Student** - Age 21, Engineering, balanced practical views
4. **International Student** - Age 23, Computer science, global perspective
5. **Working Student** - Age 24, Part-time student, focused on financial stability

Each bot participant is automatically assigned a persona based on their ID.

## Performance Considerations

**LLM bot testing is MUCH slower than random testing:**

- **Random bots**: ~0.01 seconds per question
- **LLM bots**: ~1-5 seconds per question (depending on hardware)

For a survey with 50 questions and 10 participants:
- Random: ~5 seconds total
- LLM: ~500-2500 seconds (8-40 minutes) total

**Recommendations:**
- Use LLM testing for **quality** (realistic data for analysis)
- Use random testing for **speed** (quick validation of survey flow)
- Start with fewer participants when testing with LLM

## How It Works

### 1. Question Extraction

The system reads your `questions.json` files to get:
- Question text in English/German
- Answer options with values and labels
- Question types (radio, slider, number, etc.)

### 2. Prompt Construction

For each question, it builds a prompt like:

```
You are a politically progressive student, age 22, studying social sciences.
You're concerned about social issues and economic inequality.

Question: How do you judge the current general economic situation in Germany?
Options:
  0: Very bad
  1: Bad
  2: Neither good nor bad
  3: Good
  4: Very good

Respond with ONLY the option number.
```

### 3. LLM Response

The LLM generates a contextually appropriate response based on its persona.

### 4. Parsing & Validation

The system:
- Extracts the numeric value from the response
- Validates it's within acceptable ranges
- Falls back to random if parsing fails

## Troubleshooting

### "ollama package not installed"
```bash
pip install ollama
```

### "Ollama server NOT running"
```bash
# Start Ollama in a separate terminal
ollama serve
```

### "No models found"
```bash
ollama pull llama3.2
```

### Responses are inconsistent
- Try increasing the model size: `ollama pull llama3.1`
- Adjust temperature in `llm_bot_helper.py`

### Too slow
- Use a smaller model: `llama3.2` (fastest)
- Reduce number of participants
- Use random testing for quick validation

## Tips

1. **Start small**: Test with 3-5 participants first to verify it works
2. **Monitor progress**: The script prints each bot's progress
3. **Use for analysis**: LLM-generated data is much better for testing analysis pipelines
4. **Mix approaches**: Use random for CI/CD, LLM for data quality testing
5. **Check your questions.json**: Make sure all questions have proper English/German text
